##### Abstract

Remote microphone arrays can improve speech intelligibility in multi-speaker assistive-listening scenarios, but conventional beamformed outputs are monaural, temporally misaligned with the listener's earpiece signals, and do not preserve binaural spatial cues. This work proposes a geometry-driven binaural reconstruction framework using a remote microphone array.

The system beamforms the target talker, estimates relative propagation delay from scene geometry, temporally aligns the enhanced signal with the hearing-aid microphones, and then reconstructs binaural cues using either geometry-based HRTF spatialization or a hybrid geometry-initialized adaptive filter. The geometric approach enables immediate switching between talkers, while the adaptive extension improves robustness to geometric estimation errors and converges faster than fully adaptive baselines.

Experiments with an Eigenmike array and KEMAR manikin show that the proposed methods preserve interaural timing and level cues while providing useful signal enhancement for dynamic conversational listening.
